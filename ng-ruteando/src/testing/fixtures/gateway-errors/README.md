# Errores del gateway

Cuerpos de error reales del gateway, capturados el 2026-10-28 con datos ficticios (correos `example.invalid`, contraseñas y tokens de ejemplo).

Están aparte de `../gateway/` porque ese directorio lo regenera `scripts/extract-gateway-fixtures.mjs` desde la colección de Postman, que no trae respuestas de error: ahí se perderían. Mismo formato (`name`, `request`, `response`).
